# NEXT NATION 전장 뷰어 / 플레이어

대회용 게임 `NEXT NATION`을 **눈으로 보고 직접 해보기** 위한 GUI 도구입니다.
대회 채점기(`testing-tool.py`)가 만든 로그를 읽어 원형 전장을 그립니다.

세 가지 모드를 지원합니다.

1. **리플레이** — 이미 끝난 게임(log.txt)을 열어 turn-by-turn 으로 감상
2. **실시간 관전** — 대국을 진행하면서 실시간으로 전장을 관전 (시드/랜덤 선택)
3. **직접 플레이** — 사람 vs AI 로 직접 대국 (연습용)

---

## 폴더 구성

```
next_nation_gui/
├── viewer.html            # 메인 화면 (이 파일을 연다)
├── viewer_core.js         # 파서·렌더러·타임라인·라이브 로직
├── d3-delaunay.min.js     # 보로노이 셀 생성 라이브러리(로컬 사본)
├── viewer_server.py       # 실시간 관전·새 게임·직접 플레이용 브리지 서버
├── human_player.py        # 직접 플레이용 사람 프록시
├── testing-tool-practice.py  # 직접 플레이용 채점기 사본(시간제한 완화)
├── sample_log.txt         # 예시 로그(바로 "샘플 보기"로 확인 가능)
└── assets/                # 게임에 쓰이는 이미지 (자유롭게 교체)
    ├── hq_left.png  hq_right.png
    ├── base_left.png  base_right.png
    └── warrior_left.png  warrior_right.png
```

> 이 도구는 **게임 규칙을 다시 계산하지 않습니다.** 모든 판정은 대회 채점기가 하고,
> 뷰어는 그 결과(로그)를 그릴 뿐이라 채점기와 어긋날 일이 없습니다.

---

## 1. 리플레이 (가장 간단)

로컬 서버로 여는 것을 권장합니다(이미지·샘플 로딩 때문).

```bash
cd next_nation_gui
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000/viewer.html
```

- 우측 상단 **로그 열기** 로 `log.txt` 선택, 또는 화면에 드래그&드롭
- **샘플 보기** 버튼으로 동봉된 예시 로그 즉시 확인
- 아래 타임라인에서 ◀ ▶ / 재생 / 슬라이더 / 배속으로 탐색
  (키보드 ← → 로 한 날씩, 스페이스로 재생/정지)

로그를 만드는 법(채점기):

```bash
# 프로젝트 폴더(testing-tool.py 가 있는 곳)에서
python3 testing-tool.py --seed 42 -l log.txt \
  -a "python3 sample-code.py P1" -b "python3 sample-code.py P2"
```

## 2. 실시간 관전 + 새 전장 생성 (시드/랜덤)

브리지 서버를 **프로젝트 폴더 기준**으로 실행합니다.
(서버가 채점기와 AI 들을 실행하므로, 그들이 있는 경로를 알아야 합니다.)

```bash
# 방법 A: 뷰어 폴더와 프로젝트 폴더가 다를 때 — 환경변수로 경로 지정
NN_TOOL=/경로/testing-tool.py \
NN_WORKDIR=/경로 \
NN_EXEC1="python3 sample-code.py P1" \
NN_EXEC2="python3 sample-code.py P2" \
python3 next_nation_gui/viewer_server.py

# 방법 B: 뷰어 파일들을 프로젝트 폴더에 복사해 두었다면 그냥
python3 viewer_server.py
```

실행 후 브라우저에서 **http://localhost:8770/viewer.html** 접속.
헤더에 **새 전장** 패널이 나타납니다.

- **랜덤**: 매번 다른 전장으로 대국 시작
- **시드**: 숫자를 입력하면 그 시드의 전장으로 시작(같은 시드 = 같은 맵, 재현 가능)
- **▶ 대국 시작** 을 누르면 대국이 진행되며 전장이 실시간으로 갱신됩니다.

대국이 끝나면 그대로 타임라인으로 되감아 다시 볼 수 있습니다.

> 매 게임 전장이 새로 초기화되는 규칙은 채점기의 맵 생성기가 담당합니다.
> 뷰어는 시드만 넘기고, 생성된 전장을 받아 그립니다.

대전할 AI 를 바꾸려면 `NN_EXEC1` / `NN_EXEC2` 환경변수를 자신의 프로그램으로 지정하세요.

## 3. 직접 플레이 (사람 vs AI)

브리지 서버를 띄운 뒤(2번과 동일), 브라우저 헤더의 **🎮 직접 플레이** 버튼을 누릅니다.

```bash
# 프로젝트 폴더(testing-tool.py·sample-code.py 가 있는 곳)에서
python3 viewer_server.py
#   다른 폴더면: NN_TOOL=..., NN_WORKDIR=... 환경변수로 지정 (2번 참고)
```

진행 순서:

1. 헤더에서 **랜덤** 또는 **시드** 를 고르고 **🎮 직접 플레이** 클릭
2. 진영 선택 창에서 LEFT(왼쪽 빨강) / RIGHT(오른쪽 파랑) 결정
3. 내 차례가 되면 우측 하단에 **조작 패널**이 열립니다.

**조작 방법 (클릭 + 패널 병행):**

- **이동**: 내 전사가 있는 칸을 클릭(전사 선택, 금색 테두리) → 목적지 구역 클릭.
  같은 칸을 다시 누르면 선택이 해제됩니다.
- **건설·업그레이드**: 거점 또는 본부 칸을 클릭하면 명령 목록에 추가됩니다.
  (전사가 그 칸에 이미 있어야 실제로 수행됩니다. 이동한 턴이 아니라 도착한 다음 턴에 건설하세요.)
- **훈련**: 패널의 훈련 입력칸에 숫자를 넣습니다(본부 레벨별 가능 수 표시).
- 명령 목록에서 ✕ 로 개별 취소, **초기화** 로 전체 취소.
- 다 구성했으면 **제출 ▶**. 상대(AI)·채점기 처리가 끝나면 다음 내 차례가 옵니다.

전장과 우측 패널은 매 턴 자동으로 갱신되고, 게임이 끝나면 결과 배너가 뜹니다.
끝난 뒤에는 타임라인으로 되감아 복기할 수 있습니다.

> **시간제한**: 정식 채점은 한 턴 100ms 라 사람이 둘 수 없습니다.
> 직접 플레이는 서버가 자동으로 **연습용 채점기 사본(`testing-tool-practice.py`)** 을 사용해
> 턴당 제한을 사실상 없앱니다(약 16시간/턴). 이 모드의 결과는 정식 채점과 무관한 연습용입니다.

> 대전 상대 AI 를 바꾸려면 서버 실행 시 `NN_EXEC2`(상대) 환경변수를 지정하거나,
> 코드에서 `/human/new` 의 `ai` 값을 바꾸세요. 기본은 `sample-code.py` 입니다.

## 이미지 교체 (자유롭게 수정 가능)

`assets/` 폴더의 PNG 를 **같은 이름으로 덮어쓰기** 하면 게임에 바로 반영됩니다.
코드를 고칠 필요가 없습니다.

| 파일 | 의미 |
| --- | --- |
| `hq_left.png` / `hq_right.png` | 좌(A)·우(B) 본부 |
| `base_left.png` / `base_right.png` | 좌·우 기지 |
| `warrior_left.png` / `warrior_right.png` | 좌·우 전사 토큰 |

- 권장 규격: 정사각형 PNG(투명 배경), 128×128 이상
- 해당 이미지가 없으면 자동으로 **기본 도형(SVG)** 으로 그려집니다.
  (이미지가 깨지거나 비어 있어도 게임은 정상 동작)

## 화면 읽는 법

- 보드 바깥쪽 원이 전장. 왼쪽 끝 빨강이 **LEFT(A) 본부**, 오른쪽 끝 파랑이 **RIGHT(B) 본부**
- 금색 테두리 셀이 **거점**(기지 건설 가능)
- 셀 위 마커: 건물(본부=별, 기지=집), 그 아래 **HP 바**, **Lv** 표시
- 작은 원형 배지: 해당 구역의 전사 수(좌=빨강, 우=파랑)
- 셀에 마우스를 올리면 상세(건물 레벨·HP·포탑, 전사별 HP) 툴팁
- 우측 패널: 본부 HP, 추정 금화, 전사·건물 수, 남은 초읽기, 그날의 사건 목록

> **금화는 추정치**입니다. 채점기는 금화를 로그에 남기지 않으므로
> 비용·노동수입·식비를 규칙대로 계산해 보여줍니다(예시 로그 기준 실제값과 일치 확인됨).

## 자주 묻는 점

- **샘플/이미지가 안 떠요** → `file://` 로 직접 열면 브라우저 보안 때문에 막힙니다.
  반드시 `python3 -m http.server` 같은 로컬 서버로 여세요.
- **새 전장 패널이 안 보여요** → 그 기능은 브리지 서버(`viewer_server.py`)로 열었을 때만 켜집니다.
  단순 리플레이는 패널 없이 동작합니다.
- **인터넷이 없어요** → `d3-delaunay.min.js` 로컬 사본이 포함되어 오프라인에서도 됩니다.
